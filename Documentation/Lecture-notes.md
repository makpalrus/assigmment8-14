# Конспект лекций для проекта Unity 2D

## 4. Спрайты и эффекты
- Sprite Mode Multiple → Slice по размеру ячейки → клип → Animator. В примере ячейка 128×128, PPU 128, Point и без компрессии.
- Idle и Walk зациклены, переходы по Speed без Has Exit Time для мгновенной реакции. Grounded для прыжка, SpriteRenderer.flipX для разворота. Ориентир для пиксельной анимации 6–12 FPS.
- Монеты и огонь можно зациклить без кода. Particle System подходит для дыма и искр.

## 5–6. Игровые скрипты
1. Стрельба через Instantiate, кулдаун через Time.time, удаление снарядов через Destroy с задержкой.
2. Спавнер через InvokeRepeating и Random.Range.
3. Однократный взрыв через Invoke.
4. Временная неуязвимость и мигание через корутину с WaitForSeconds.
5. Урон и лечение через Health и GetComponent<T>.
6. Варианты Hazard через virtual и override.
7. Перезапуск сцены через SceneManager.LoadScene.
8. Таймер через Time.deltaTime.
9. Звуки событий через AudioSource.PlayOneShot.

## 7. Input System
- PlayerInput и действия Move (Vector2), Jump и Fire (Button). Один контроллер обслуживает клавиатуру, геймпад и сенсорный UI. Пример лекции использует Send Messages.
- On-Screen Stick → <Gamepad>/leftStick, Jump → buttonSouth, Fire → buttonWest. Для EventSystem нужен InputSystemUIInputModule. Both допустим при миграции старого ввода. Критерий задания — убрать Input.Get… из игрового кода.

## 8–9. Мобильный UI и подготовка проекта
- Canvas Scaler → Scale With Screen Size. В лекции 7 у стика пример Match 0.5, в лекции 8 для landscape рекомендуется 1920×1080 и Match 1, для portrait — 1080×1920 и Match 0.
- HUD и кнопки внутри панели Screen.safeArea. Стик снизу слева, действия снизу справа, здоровье и пауза сверху. Фон на весь экран. Проверка в Device Simulator на 16:9, телефоне с вырезом и планшете, затем на телефоне.
- Поток экранов включает меню, игру с HUD, паузу и результат. При выходе из паузы перед сменой сцены восстановить Time.timeScale.
- Core loop в 3–4 действиях, GDD на 1–2 страницы с MVP и списком отложенных идей. В Git хранят Assets, Packages, ProjectSettings и .gitignore. Visible Meta Files и Force Text. Разделять работу над сценами и использовать префабы.

## 10. ИИ врагов
- FSM: восприятие → решение → действие. Зрение в 2D проверяет дистанцию, угол и стену через Physics2D.Raycast с маской препятствий. Ссылка на игрока задаётся один раз, зрение можно опрашивать через 0.1–0.2 с.
- Патруль по точкам сцены. При Rigidbody2D движение через MovePosition в FixedUpdate. У каждого состояния есть выход, SetState сбрасывает таймер.
- Три архетипа лекции: патрульный замечает и преследует, стрелок держит дистанцию и целится, таранщик готовится и делает рывок. Атака читается по предупреждению, после удара есть окно восстановления. Уйти из зоны удара должно быть возможно.
- Отладка через Gizmos, Debug.DrawRay и подписи состояний. В плейтесте ориентир 2–4 попытки у нового игрока. Менять один параметр за раз и записывать результат.
- Для задания лекция просит decision log на 3–5 строк о работе с агентом. Это критерий учебного задания, а численные значения и архетипы в лекции — примеры для настройки под игру.

## Как Skybound использует лекции

- **4.** Player.controller переключает существующие Idle, Run, Jump и Fall по Speed, Grounded и VerticalSpeed без Has Exit Time. Player передаёт параметры и разворачивает спрайт. Монеты перебирают кадры в CollectibleCoin; при движении платформы монета сохраняет положение относительно неё.
- **5–6.** PlayerHealth использует корутину для мигания и неуязвимости. EnemyBrain — общий базовый класс трёх врагов. FinishGate и MobileGameUI меняют или перезагружают сцену, GameAudio играет короткие эффекты через PlayOneShot. Стрелок создаёт снаряд, EnemyProjectile удаляет его при попадании или истечении времени. Отдельные упражнения с бомбой, повторяющимся спавнером и победой по таймеру в уровни Skybound пока не добавлены.
- **7.** SkyboundControls содержит Move и Jump. PlayerInput вызывает OnMove и OnJump; экранные элементы используют leftStick и buttonSouth виртуального геймпада. В игре пока нет стрельбы игрока и действия Fire.
- **8–9.** Canvas Scaler использует 1920×1080 и Match 1. SafeArea применяет Screen.safeArea. Есть главное меню, HUD, пауза, экран проигрыша и GDD. Проверка новых изменений в Device Simulator и на телефоне остаётся отдельным шагом.
- **10.** На Level2 есть Patroller, Shooter и Charger с собственными FSM, SetState, предупреждением и восстановлением. EnemyBrain проверяет дальность, угол, стену и видимость в кадре. У Patroller две точки в сцене. При выборе врага Gizmos показывают радиус и угол зрения. Птица на Level3 — контактная ловушка.
